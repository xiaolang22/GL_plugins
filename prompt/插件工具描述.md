## create sheet
当需要为特定日期/场次创建订座工作表时调用此工具。适用于以下场景：
- 用户说"创建明天的订座表"、"新建9月26日的午市和晚市"
- 用户尝试对一个不存在的表进行更新记录、添加记录、删除记录操作之前
- 系统初始化后需要补充未来某一天的空白订座表
- 支持单独创建午市或晚市，也支持同时创建两场

特别注意：
1. 不能创建今天之前的日期，不能与已有工作表重名
2. **保证必要信息完备性**：调用该工具的时候必须填写的两个输入参数是date和sessions。日期是必须要用户提供的，若用户没有提供，则要询问用户；对于场次，若用户没提，则默认是午市和晚市都要，若用户特别说明是午市/晚市，则按照用户说明的来。

## delete sheet
当需要删除某个日期的订座工作表时调用此工具。适用于以下场景：
- 用户说"删除9月26日的订座表"、"删掉这个过期的工作表"
- 清理已过期或不需要的工作表
- 注意：不能删除模板工作表，不能删除文档内最后一张子表

特别注意：
1. **保证必要信息完备性**：调用该工具的时候必须填写的两个输入参数包括date和session。两者都需要用户提供，若不确定，需要询问用户，不能靠猜。
2. **删除操作确认**：在正式执行该删除操作之前，需要先确认用户的删除意图和待删除内容，得到用户明确的确认删除指令后方可继续调用该工具

## update record
用于改工作表的记录内容。适用以下场景：
- 用户说"把10月1日3号桌人数改成10人"
- 更新订座信息和座位信息字段
- 取消订座时清空记录的订座信息字段
注意：
1. 不允许在调用工具的时候尝试更新是否已订、座位名称字段。其中，是否已订字段由后台自动更新，座位名称用于唯一定位工作表中的记录
2. 在调用此工具之前务必先调用query_records工具查看要修改的记录原本的内容。对于不需要更新的字段，需要在field中对应键值对填写字段原本的值以避免删除该字段。
3. 保证必要信息完备性：必须填写的输入参数包括date、session和seat_name。三者都要用户提供，若不确定需要询问。

## add record
当需要在某个工作表中添加新的座位记录时调用此工具。适用于以下场景：
- 用户说"今天晚市加一个临时桌"
- 添加座位并同时填写座位信息，或者仅添加一个新座位但不填其他座位信息
- 默认值 ：座位类型为"大厅"，是否已订按规则自动判断

特别注意：
1. 该工具的输入参数中的fields参数仅允许更新工作表的座位类型、座位容量、座位备注三个字段，仅通过调用该工具不允许更新工作表的订座信息字段
2. 保证必要信息完备性：调用该工具的时候必须填写的输入参数包括date、session和seat_name，三者都需要用户提供，若不确定，需要询问用户，不能靠猜。

## delete record
当需要删除某个座位记录时调用此工具。适用于以下场景：
- 用户说"删掉今天的临时桌A"、"删除那个加的座"
- 按座位名称查找并删除

特别注意：
1. **保证必要信息完备性**：调用该工具的时候必须填写的输入参数包括date、session和seat_name，date和session用于定位工作表，seat_name用于定位记录。三者都需要用户提供，若不确定，需要询问用户，不能靠猜。
2. **删除操作确认**：在正式执行该删除操作之前，需要先确认用户的删除意图和待删除内容，得到用户明确的确认删除指令后方可继续调用该工具

## query record
当需要查看某天某场次的所有订座信息时调用此工具。适用于以下场景：
- 用户说"看看9月26日晚市的订座情况"、"查一下明天中午有多少人预订"
- 用户说"明晚订个房间，有窗户的最好，6个人，看看有没有合适的位置"
- 查看可用座位（未订座）和已订座详情
- 查询是否满足特定人数需求的可用座位
- 返回格式化的 Markdown 表格，便于大模型阅读

## print
用途:
打印外卖单/自提单。对订单信息做结构化提取。调用打印机按固定格式打印。

注意：
调用一次该工具仅能完成一次打印。

约束:
严格按原文抄单，禁止修饰或修改文本
仅做结构化提取与排版，不变动文字内容

接口的格式说明：
{  "lines": ["文本1|样式1,样式2", "文本2|样式1,样式2,样式3", "..."]}
以下是一个输入body示例：
{"lines": ["标题|center,bold,double", "内容|left"]}
