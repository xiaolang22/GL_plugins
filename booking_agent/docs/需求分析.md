## 迭代一阶段需求
- [ ] 创建表格：机器人需要周期性地按照预设模板，提前创建好一定数量的空白表格。默认是每隔一个月批量创建一个月数量的表格（需要对齐实际日历天数）。
- [ ] 支持调整预设模板：若座位信息发送长期性变动，允许通过自然语言或人工修改模板
- [ ] 内容更新：人可以通过自然语言更新表格内容。主要是三种更新场景。第一种：添加座位，需要新建记录，并补充完整座位信息；第二种：修改座位信息，修改座位信息字段；第三种：修改订座信息，修改订座信息字段，修改任意订座信息需要同步更新是否订座标签
- [x] 优先显示：已订座的记录优先显示。
- [ ] 更新记录：记录每一次操作的责任人和时间，责任人名称为触发机器人更新表格内容的企业微信用户的名称
- [ ] 对话反馈：插件调用成功后，机器人需要返回更新结果，并按照特定格式润色表达后输出。若订座信息不完整，需要给予提示
